# Human metadata gate

The manuscript source still carries an explicit `[to be completed by the lab]`
author placeholder. The public package therefore uses the neutral group label
`IMUT research team (author list to be confirmed)` in `CITATION.cff` and does
not infer individual authors, affiliations, emails or a DOI.

Before a DOI is minted or the repository is cited as the final paper release,
the lab should replace that group label with the approved author list and
affiliations. This metadata gate does not affect the code/derived-output
licences or the reproducibility checks.
